# Artwork and garment provenance

The supplied design PNGs are copied intact into `public/designs`. The source
filename for each is retained as `sourceGraphic` in the catalog data.
`live-forever-eos.png` was hash-checked against **live forever eos.png** and is
byte-for-byte identical. `no-hunting-humans.png` is the supplied **image.png**.

Original garment views come from the supplied Designs archive. The following
four additional views were generated with the built-in imagegen tool and are
labeled as concepts on their product pages:

| Asset | Brief and source references |
| --- | --- |
| `no-hunting-front.png` | Match the supplied white long-sleeve model's studio composition. Apply the supplied woodland bark/leaves camouflage across the garment, with blaze-orange arched “NO HUNTING” and straight “HUMANS” across the front. |
| `no-hunting-back.png` | Match the back-facing long-sleeve model and the supplied camo artwork. All-over camo, no added lettering on the back. |
| `majesty-black-back.png` | Change the supplied white Majesty Building long sleeve to black. Preserve the blue tower graphic; make its surrounding title and captions white for contrast. Keep the model and pale background. |
| `majesty-black-front.png` | Change the supplied white front-view long sleeve to black. The small left-chest “I4 / EYE / SORE” print becomes white. Keep the catalog framing. |

These are visual production concepts. Sleeve lettering is not visible in the
generated front/back poses; the original white variant includes sleeve views.
The creator must approve final placement and print files before manufacturing.

The header wordmark uses Montserrat ExtraBold glyph outlines in SVG. Montserrat
and IBM Plex Mono font licenses are included alongside this file. Font binaries
are bundled by Vite from the declared Fontsource dependencies.
